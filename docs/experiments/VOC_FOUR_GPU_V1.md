# 新工程VOC15+5四卡正式基线

2026-11-05。用户明确要求使用物理GPU0、1、2、3完成当前工程的VOC正式两阶段实验。启动前四卡均为12MiB、0%利用率；不停止其他人的作业。本轮不启动COCO长训练，不增加创新模块。

## 固定设置

沿用VOC15_5_PROTOCOL.md的完整4473/1006训练图、4952测试图、900 query、完整多尺度、完整OGC预训练权重和同一个24处FFN LoRA。Task1旧15类提示，Task2累计20类提示、仅新5类标注；两阶段各12epoch，seed20261103、学习率1e-4、第10epoch后降为1e-5，固定末尾模型评价。

四卡采用原生DDP，即四张卡各处理一份图像，再同步梯度共同更新同一个模型。每卡batch1、累积1步，合计每次更新4张图；原单卡配置为batch2、累积2步，同样有效batch4。配置见configs/experiments/voc15_5_4gpu.json。每个训练rank核对实际初始化，检查冻结参数哈希、LoRA更新和四卡最终LoRA完全一致。

有效batch一致不代表逐批数值完全相同：分布式损失归一化、图像增广、图像padding和采样顺序均可能与单卡/历史双卡不同。原生分布式采样每epoch将Task1的4473图补齐为4476次曝光（重复3次），Task2的1006图补齐为1008次曝光（重复2次）。每阶段1119/252更新每epoch，12epoch共13428/3024更新。这是单seed新四卡基线，不将差异归因于新方法。

正式B1从W0开始，B2从B1末尾epoch_12.pth继续同一个LoRA，跨阶段重置优化器；每阶段保留完整checkpoint状态。两次完整评价均用全部20类提示、全部4952图。B0复用本工程当天已完成的新完整冻结评价，明确记录来源哈希，不重复推理。
