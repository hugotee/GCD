# 候选研究问题与最小验证

2026-11-04。以下是可否定的研究问题，不是已确定的创新点。五篇核心证据见 literature_matrix.md。此前独立 Single LoRA 单 seed 结果已产生真实遗忘，但不能由 AP 差值反推原因。

## RQ1：参数变化、提示集合扩大与区域—文本对应变化，分别贡献多少旧类下降？

**已有工作。** GCD处理师生 query/文本不对应并蒸馏同模态拓扑；C²Path在其上进行类别 token 条件适配；DitHub 多类提示会触发专家组合。它们没有替本项目证明旧类下降来自哪条具体路径。

**当前假设。** 冻结 BERT 不足以保证融合后文本稳定；提示15→20也可能改变竞争与对应。是否是主要遗忘来源仍待验证，不能把“跨模态漂移”当成已识别根因。

**最小实验。** 优先复用 B0/B1/B2：固定图像、原尺寸和20类提示，用每类 AP/召回、分类与定位误差筛出损失最大的类别；再做固定模型×15/20类提示的配对分析。提示对照只比较旧15类，并固定 GT、负类处理和检测预算。用 GT 区域匹配或教师 query 锚定探针比较融合前后文本与区域—文本分数，避免直接比较两个模型同序号 query。隐藏 GT 仅用于诊断，绝不回流 B2 训练监督或选择 test 最佳配置。

**简单对照/否定条件。** 同一模型同一提示重复推理作为数值噪声基线；仅增加无关文本检验提示长度效应。如果固定提示后文本关系和跨模态分数稳定，而下降主要来自框召回，则缩小或放弃跨模态结构主因假设。二维 t-SNE 不能单独证明机制。

**成本。** 已完成CPU缓存分析，约154.47秒；GPU2的128图、六条件、900query特征探针计时区间186.66秒，初次模型构建另计，峰值allocated 1.462GiB。该前向成本不能替代新增反传或重训预算。当前仅GPU2获本轮使用范围，执行前仍检查空闲。

**价值。** 优先级最高。先解释 person/chair/diningtable 等下降是否集中在漏标共现和特定交互位置，再决定是否研究保持约束。

## RQ2：共享 Single LoRA 的类间梯度冲突是否独立于漏标背景冲突？

**已有工作。** C²Path已经研究类别条件路径；DitHub已有类别模块与共享 B；因此“加类别专家”本身不能作为新颖性声明。GCD明确提示蒸馏对应失配也会引入有害梯度。

**当前假设。** 类别对的负梯度内积可能解释部分退化，但也可能仅由旧对象被当背景产生；低秩因子重参数化还会影响参数空间相似度。

**最小实验。** 从同一 B1 checkpoint，在训练侧固定小探针集计算当前检测损失、旧类诊断损失对同一组 LoRA 的梯度内积、范数和层分布；同时分别统计含/不含旧对象的Task2图像。诊断分支可读取完整训练侧标注以归因，但无保持baseline依旧只用新类GT更新。额外比较函数更新量或 BA 的变化，避免仅依据 A/B 梯度得结论。

**简单对照/否定条件。** 同类不同样本梯度、随机类别对、等rank/等参数预算的视觉侧/文本侧LoRA；控制正负样本和匹配后，若冲突与后续功能下降不相关，或单纯纠正监督即可消除现象，不主张独立类别路径机制。纠正监督是 oracle 诊断，不进入合法无回放主表。

**成本。** 每探针多次反传；先几十个batch、单卡batch1，无需启动完整12epoch。真实显存和时间先在GPU2空闲时测量；不将两卡显存相加。

**价值。** 次于RQ1。必须证明在控制漏标和query匹配后仍存在稳定现象，才值得设计新参数约束。

## RQ3：已适配类别的保留，与预训练但增量未适配类别的保留，是否需要不同约束？

**已有工作。** ZiRa、DitHub、MR-GDINO已经显式研究零样本保留；这不是无人研究的问题。GCD/C²Path的已见类COCO主表不能回答其未适配类别能力。MR的检索回退和ZiRa的小残差也不等价于同一单模型持续保持。

**最小实验。** VOC15+5先作为机制试验；B1的新5类只称增量尚未监督类别，B2后VOC20类全部适配，不能再用它们证明未适配类保留。后续核实COCO，冻结与VOC语义不重叠的额外评价类别集合、同义词映射和预训练覆盖说明；比较W0/B1/B2，报告old/new/unadapted绝对AP和保持—适应曲线。数据未就绪前不填未见类AP。

**简单对照/否定条件。** Frozen、Single LoRA、一个经过query对应核验的基础KD或一个残差约束，分别单独加入；统一训练/推理预算。不拼装五篇模块。若未适配类能力未下降，或提升完全来自推理类别先验/回退原模型，则收缩问题，不宣称解决单模型跨模态遗忘。

**成本与价值。** 离线额外评价为主；KD训练增加教师前向和参数存储，需实测后预算。先建立额外测试集，再决定投入，当前优先级第三。

## 首轮诊断补充（2026-11-04）

已完成全test缓存与GPU2的128图raw900-query配对诊断，见[机制诊断报告](../experiments/MECHANISM_DIAGNOSTICS_V1.md)。在固定训练侧样本中，几何候选可用时旧类分数仍大幅降低；pre-encoder文本不变而增强后文本改变。该结果缩小了RQ1的检查位置，并提示先做B2训练prompt new5/all20的单变量对照；仍不构成机制因果或新颖性证明。
