# 科研项目启动：Grounding DINO + PEFT + Class-Incremental Object Detection

## 一、项目背景与目标

我目前是计算机视觉方向的研究生，研究领域为 Continual Learning + Object Detection。

经过前期文献阅读、DGS 论文复现和实验分析，我已经决定调整科研主线：

**Pretrained Vision-Language Models for Class-Incremental Object Detection（VLM-based CIOD）**

目前确定：

- 基础模型：完整预训练 Grounding DINO-T。
- 训练方式：PEFT，优先采用 LoRA。
- 研究任务：Class-Incremental Object Detection（CIOD）。
- 数据集：Pascal VOC2007 + MS COCO2017。
- 初期实验：VOC 15+5。
- 后续正式验证：COCO 70+10、40+40。
- 算力条件：日常可使用两张 RTX 3090，但应首先核实具体 GPU 使用权限。
- 最终目标：寻找 VLM 类别增量学习中尚未充分解决的具体问题，形成具有独立创新性的研究方法。

**我已经新建了一个 GitHub 仓库，作为新的独立科研项目。**

此前的 DGS 项目主要用于复现 CVPR 2026 论文，不再作为本项目的主体。

允许参考、复用经过审计且符合许可证要求的 DGS 工程模块，但新项目必须独立，不能继承其动态分组、任务路由、参数合并等核心方法。

首先识别当前 Git 仓库根目录，不要默认新项目仍位于旧 DGS 路径。

## 二、研究参考文献

目前准备以五篇论文为核心参考：

### 1. GCD（AAAI 2025）

Advancing Vision-Language Models for Incremental Object Detection via Global Alignment and Correspondence Distillation

https://ojs.aaai.org/index.php/AAAI/article/view/32864

重点关注：

- Global Alignment（GA）。
- Semantic Correspondence Mechanism（SCM）。
- Correspondence Response Distillation（CRD）。
- Correspondence Topology Distillation（CTD）。
- Semantic Structure Collapse。
- Teacher/Student Query 对应问题。
- 旧类别语义结构保持与跨模态遗忘。

### 2. C²Path（2026 arXiv 预印本）

Class-Conditional Pathway Decoupling for Vision-Language Incremental Object Detection

https://arxiv.org/abs/2608.21937

重点关注：

- Class-Conditional Pathway Decoupling。
- 类别相关的参数更新。
- ClassLoRA。
- 不同类别在共享适配路径中的潜在干扰。
- 类别级参数隔离与共享机制。
- 与 GCD、普通 LoRA 的区别。

### 3. DitHub（NeurIPS 2025）

请从官方论文页面核实完整标题、方法、代码及实验设置。

重点关注：

- 模块化持续学习。
- 轻量化专家或适配模块。
- 不同任务知识如何组合、隔离或融合。
- 参数效率与知识干扰。
- 原始任务是否属于 CIOD、IVLOD 或其他设置。

### 4. ZiRa（NeurIPS 2024）

Zero-shot Generalizable Incremental Learning for Vision-Language Object Detection

https://proceedings.neurips.cc/paper_files/paper/2024/hash/f6f4b34d255c2c6c2391af975bed0428-Abstract-Conference.html

重点关注：

- 预训练 Grounding DINO 的持续适应。
- 轻量化适配机制。
- Zero-Interference Loss。
- 如何保持预训练模型的 Zero-shot 能力。
- 旧类、新类与未见类知识之间的关系。

### 5. MR-GDINO（2024 arXiv 预印本）

MR-GDINO: Efficient Open-World Continual Object Detection

https://arxiv.org/abs/2412.15979

重点关注：

- Memory / Retrieval 相关机制。
- Open-world Continual Detection。
- 已学习类别与未见类别的检测能力。
- 预训练知识保持。
- 推理阶段的知识检索、融合或选择。

以上是研究参考，而不是要求完整复现五篇论文。

**必须依据论文原文与官方代码核实内容。不得仅根据我的研究描述推断具体实现。**

## 六、任务四：第一组基线实验

第一阶段只需要三个模型状态。

### B0：Frozen Grounding DINO-T

加载完整预训练模型，不进行训练。

在 VOC2007 test 上评估全部 20 类。

记录：

- 旧 15 类 AP。
- 新 5 类 AP。
- 全部 20 类 AP。
- 逐类别 AP。

目的：建立预训练模型的初始检测能力参考。

### B1：Task 1 Single LoRA

从 B0 的预训练权重出发。

冻结主体参数，通过 Single LoRA 学习旧 15 类。

训练后保存 checkpoint。

评估全部 20 类。

目的：观察在旧 15 类监督下，模型的类别检测能力发生什么变化。

### B2：Task 2 Sequential LoRA

从 B1 的 checkpoint 出发。

继续使用同一个 LoRA，学习新增 5 类。

第二阶段不使用旧数据回放、不加入知识蒸馏、不添加新模块。

保存最终 checkpoint。

再次评估全部 20 类。

输出：

| Model | Old 15 AP | New 5 AP | All 20 AP |
|---|---|---|---|
| B0 Frozen | | | |
| B1 Task 1 | | | |
| B2 Task 2 | | | |

同时输出：

- AP50。
- AP@[0.50:0.95]。
- Per-class AP。
- 旧类别遗忘程度。
- 新类别适应收益。
- 与初始预训练模型性能的差异。

不得虚构 AP 或将 smoke test 结果当作正式结果。

## 七、任务五：计算资源评估

由于日常仅有两张 RTX 3090，所有实验必须考虑计算成本。

开始正式训练之前，使用完整 Grounding DINO + LoRA 训练路径进行 GPU smoke test 和性能测量。

先核实 GPU 使用权限。此前实验曾明确要求仅使用 GPU0；未经新的授权，不得擅自使用 GPU1/2/3。

测试内容：

- 完整模型前向。
- 检测损失。
- LoRA 梯度反向传播。
- 参数更新。
- 模型保存与加载。
- 评估流程。

完成 100–300 step 的稳定吞吐测量，记录：

- 峰值显存。
- Batch Size。
- 图像输入尺寸。
- Detection Query 数。
- 每 step 耗时。
- Images/s。
- GPU 利用率。
- 实际训练图像数。
- 完整 B1/B2 的预计训练时间。

优先进行正确性和资源测试，不直接启动可能持续数十小时的训练。

只有在实验协议、数据和运行成本明确之后，才启动正式训练。

不得为了加速而无记录地改变图像分辨率、训练数据比例或类别顺序。
